# Idle

**Live:** https://vishnuvsdevtech.github.io/idle-behaviour/

The page notices when you stop. Eight seconds of stillness and the room changes: the lamp dims to 42%, dust thickens, and a moth arrives to circle the light.

**How:** Idleness is the one input every interface ignores. Any pointer movement resets the timer and the lamp comes back over about a second, so the idle state can never trap anyone.

**What it is not:** Decoration on a timer, never a task.
